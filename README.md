# Mino Totally Free Open

A small, free-to-use coding-learning website with guided lessons, practice questions, learning paths, project prompts, and an in-browser HTML playground.

## Run it locally

Open `index.html` in a modern browser. The app is static HTML, CSS, and JavaScript; it does not need a build step or server. Learning progress and project drafts are stored in the browser on your device.

## Publish with GitHub Pages

This repository deploys the static site to GitHub Pages from the `main` branch using the workflow in `.github/workflows/pages.yml`. After the first successful deployment, the site is available at:

`https://Karan1099896.github.io/mino-totally-free-open/`

## What's included

- `index.html` and `dashboard.*` — the learning dashboard and course experience.
- `home.html` and `styles.css` — the public landing page.
- `app.js` — landing-page interactions.

The learning material in this project is original explanatory content organized around common front-end and full-stack topics.
